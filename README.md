# Nightwatch — желі аномалияларын бақылау

![Nightwatch голографиялық басты бет](assets/orbit-hero.svg)

Компьютерлік желідегі күмәнді белсенділікті анықтауға арналған, қазақ тіліндегі Streamlit веб-қосымшасының оқу прототипі. Басқару панелінде желі трафигінің қысқаша көрсеткіштері, санат графиктері және модель нәтижелері беріледі. Белгіленген деректе бастапқы үлгі мен екі классификатор салыстырылады; белгі жоқ болса Isolation Forest аномалияға ұқсас ағындарды бөлек тізімдейді.

## Қосу

Python 3.10 немесе одан жаңасы қажет.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Қосымша браузерде ашылады. Басты бетте голографиялық желі иллюстрациясы, дерек шолуы және модель панелі бар. Іске қосылғанда оқу мақсатындағы синтетикалық демо дерек көрсетіледі. Өз дерегіңді сол жақ панельдегі CSV жүктеу өрісімен енгіз.

## Дерекпен жұмыс

- CSV файлын жүктеген соң бастапқы жолдар, сандық белгілер және бос мәндер көрсетіледі.
- Белгі бағаны (`Label`, `Class`, `Attack`, `Target`, `Category`) автоматты түрде ұсынылады; басқа бағанды қолмен таңдауға болады.
- Белгіленген деректе бастапқы үлгі, Random Forest және Gradient Boosting бірдей оқыту/тест бөлінісінде салыстырылады. Дәлдік, нақтылық, толықтық, F1 өлшемі және шатасу матрицасы көрсетіледі.
- Қалыпты трафик класы таңдалған соң, басқа классқа болжанған қосылымдар **күдікті қосылымдар** деген жеке бөлімде көрінеді.
- Белгі бағанын таңдамағанда Isolation Forest аномалияға ұқсас жолдарды ұпайы бойынша реттеп, тексеру басымдығын көрсетеді.
- Үлкен файлдарда параметрлер панелінен оқытуға алынатын жол санын азайт.
- 50 MB-тан үлкен CSV файл chunk арқылы оқылады; интерфейс үшін ең көбі 50 000 жол іріктеледі. Іріктеу туралы хабарлама көрсетіледі, метрикалар сол іріктемеге есептеледі.
- Streamlit жүктеу шегі `.streamlit/config.toml` файлында 512 MB етіп орнатылған.

## Деректер жиыны

[CIC-IDS2017 ресми беті](https://www.unb.ca/cic/datasets/ids-2017.html) желілік трафик ағындарының белгіленген CSV нұсқаларын ұсынады. Алдымен шағын файлмен бастап, кейін үлкен файлды бөліктерге бөліп талдауға болады. Бастапқы деректер бұл репозиторийге көшірілмейді.

## Репозиторий құрылымы

```text
app.py             # Streamlit интерфейсі және ML ағыны
assets/            # Голографиялық басты бет иллюстрациясы
.streamlit/        # Streamlit сервер параметрлері
requirements.txt   # Python тәуелділіктері
README.md          # Осы нұсқаулық
```

## Шектеулер

Бұл — зерттеу/оқу прототипі; өндірістік желіні қорғау құралы емес. Isolation Forest дабылы шабуылды дәлелдемейді. Жіктеу метрикалары дерек бөлінуіне, сынып теңгерімсіздігіне және feature сапасына тәуелді. Дерек жиынын жариялар алдында оның лицензиясын және дәйексөз талаптарын орында.
